## 🐍 Python Backend Stack
- **FastAPI**: Modern, fast web framework for building APIs ([fastapi.tiangolo.com](https://fastapi.tiangolo.com)).
- **Uvicorn**: Lightning-fast ASGI server implementation.
- **Pydantic**: Data validation and settings management using Python type annotations.
- **PyPDF**: Pure-Python PDF library for text extraction.
- **Python-Docx**: Create and modify Word (.docx) files.
- **OpenPyXL**: Read/write Excel 2010 xlsx/xlsm files.
- **Python-PPTX**: Create and update PowerPoint (.pptx) presentations.
